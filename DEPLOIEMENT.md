# Déploiement Meditec Rapports — GitHub Pages

## 5 étapes pour mettre en ligne

### 1. Aller sur votre dépôt GitHub
https://github.com/78500meditec/psdm (ou créer un nouveau dépôt "rapports")

### 2. Créer le dossier "rapports"
- Cliquer "Add file" → "Create new file"
- Nommer le fichier : `rapports/index.html`
- Coller le contenu du fichier index.html

### 3. Ajouter les autres fichiers
Répéter pour :
- `rapports/manifest.json`
- `rapports/sw.js`
- `rapports/icon-192.png`
- `rapports/icon-512.png`

### 4. Activer GitHub Pages (si pas déjà fait)
Settings → Pages → Source: "Deploy from branch" → main → / (root) → Save

### 5. Accéder à l'application
URL : https://78500meditec.github.io/rapports/

## Installer sur le téléphone

### Android (Chrome)
1. Ouvrir l'URL dans Chrome
2. Menu (⋮) → "Ajouter à l'écran d'accueil"
3. OU attendre la bannière automatique

### iPhone (Safari)
1. Ouvrir l'URL dans Safari
2. Bouton Partager → "Sur l'écran d'accueil"

## L'app fonctionne HORS CONNEXION
Une fois installée, elle fonctionne même sans internet.
Les rapports sont sauvegardés sur l'appareil.
